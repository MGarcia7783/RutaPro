# RutaPro

RutaPro es una plataforma para gestionar rutas de aprendizaje,
objetivos, etapas, tareas y recursos de formación.

## Proyecto

Este proyecto será desarrollado como parte de una ruta de aprendizaje
Full Stack utilizando tecnologías modernas de Backend, Frontend,
Base de Datos, Docker, CI/CD y despliegue.

## Stack

### Backend
- NestJS
- TypeScript
- Prisma
- PostgreSQL

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Infraestructura
- Docker
- Docker Compose
- Git
- GitHub

## Funcionalidades principales

- Gestión de rutas de aprendizaje
- Gestión de objetivos
- Seguimiento del progreso
- Gestión de tareas
- Recursos de aprendizaje
- Autenticación de usuarios
